# Translation rules (forklift theory study aid)

Audience: adults preparing for an Australian forklift (LF) licence assessment that will be in ENGLISH.
The English text is shown directly above every translation. Translations help understanding.

1. Plain, simple, everyday language (reading age ~12). Short sentences. Friendly "you".
2. Be exact about safety. Never soften or change a rule: "never", "must", "don't", numbers, distances,
   weights and units stay exactly the same (8 m, 600 mm, 2,500 kg, 1.5 t, 000, 18 years).
3. Keep markdown structure identical: headings (##), **bold**, list markers (- or 1.), > quotes,
   tables (same number of | columns and rows; translate cell text, keep numbers).
4. Keep these in English as-is: acronyms WHS, PCBU, HSR, RTO, SDS, SWMS, PPE, LPG, CO, LF, LO, AS 2359,
   Auslan, 000, brand/model names, the formula words in "Count → Multiply → Add the pallet"
   (translate them and add the English in brackets once per segment).
5. Key assessment terms: give the translation followed by the English in brackets the first time
   they appear in a segment, e.g. 额定载荷 (rated capacity). Terms:
   hazard, risk, rated capacity, load centre, data plate, stability triangle, centre of gravity,
   counterweight, tynes, mast, exclusion zone, traffic management plan, pre-start check,
   operational check, lock out / tag out, hierarchy of control, spotter / observer,
   High Risk Work Licence, consignment note, weighbridge docket, dynamic load.
6. Quiz options: translate each option on its own; keep it the same meaning and length class
   (don't make the right answer longer or more obvious).
7. Numbers keep Australian formatting (1,500 kg). Don't convert units.
8. Video narration lines are spoken English with numbers written as words — translate the meaning
   naturally; write numbers as digits if clearer.
9. Arabic: Modern Standard Arabic. Chinese: zh-Hans = Simplified (Mainland), zh-Hant = Traditional
   (Hong Kong style, for Cantonese readers, written standard Chinese). Punjabi: Gurmukhi script.
   Filipino: standard Filipino/Tagalog (English loanwords like "forklift" are fine).
   Hindi: simple Hindi; common English loanwords (forklift, pallet) are fine.
